# Courts & Court Forms

หน้านี้เป็นข้อมูลอ้างอิงของศาลไทยที่ระบบใช้ร่วมกันทั้งระบบ
เพื่อตอบคำถามเดียวคือ **เรื่องนี้ยื่นที่ศาลไหน แล้วต้องใช้ฟอร์มอะไร**

ข้อมูลนี้เป็น master data ที่ดูแลใน [Administration](/docs/modules/administration)
และถูกนำไปใช้สร้างเอกสารใน [Documents](/docs/modules/documents)

## กฎการเลือกฟอร์ม

ศาลทั้งหมดใช้ฟอร์มตามกฎ 5 ข้อนี้ ไม่ต้องจำรายศาล

| ศาลที่ยื่น | ประเภทคดี | ฟอร์มที่ใช้ |
| --- | --- | --- |
| ศาลยุติธรรม | คดีแพ่ง คดีผู้บริโภค คดีพาณิชย์ และคดีชำนัญพิเศษ | ฟอร์มใบแต่งทนายความ (9) |
| ศาลยุติธรรม | คดีอาญา และคดีอาญาของผู้ดำรงตำแหน่งทางการเมือง | ฟอร์มใบแต่งทนายความ (อม.13) และฟอร์มใบแต่งทนายความชั้นอุทธรณ์ (อม.13/1) |
| ศาลปกครอง | ทุกประเภทคดี | ฟอร์มใบมอบฉันทะ/ใบมอบอำนาจ |
| ศาลรัฐธรรมนูญ | ทุกประเภทคดี | ฟอร์มใบมอบฉันทะ (9) |
| ศาลทหาร | ทุกประเภทคดี | ฟอร์มใบแต่งทนายความ ธน.113 |

> **ระวัง:** `ฟอร์มใบมอบฉันทะ/ใบมอบอำนาจ` ของศาลปกครอง กับ `ฟอร์มใบมอบฉันทะ (9)`
> ของศาลรัฐธรรมนูญ เป็นคนละฟอร์มกัน ห้ามใช้แทนกัน

## ฟอร์มเอกสารศาล

ระบบมีฟอร์มเอกสารศาล 6 แบบ

| ฟอร์ม | ใช้กับ |
| --- | --- |
| ฟอร์มใบแต่งทนายความ (9) | ศาลยุติธรรมฝั่งคดีแพ่งและคดีชำนัญพิเศษ |
| ฟอร์มใบแต่งทนายความ (อม.13) | ศาลยุติธรรมฝั่งคดีอาญา |
| ฟอร์มใบแต่งทนายความชั้นอุทธรณ์ (อม.13/1) | ศาลยุติธรรมฝั่งคดีอาญา ชั้นอุทธรณ์ |
| ฟอร์มใบมอบฉันทะ/ใบมอบอำนาจ | ศาลปกครอง |
| ฟอร์มใบมอบฉันทะ (9) | ศาลรัฐธรรมนูญ |
| ฟอร์มใบแต่งทนายความ ธน.113 | ศาลทหาร |

## ประเภทคดี

- คดีทรัพย์สินทางปัญญาและการค้าระหว่างประเทศ
- คดีผู้บริโภค
- คดีพาณิชย์
- คดีภาษีอากร
- คดีล้มละลาย
- คดีอาญา
- คดีอาญาของผู้ดำรงตำแหน่งทางการเมือง
- คดีเยาวชนและครอบครัว
- คดีแพ่ง
- คดีแรงงาน

## ข้อสังเกตจากข้อมูลต้นทาง

ตรวจพบรายการที่ควรตรวจสอบก่อนนำไปใช้เป็น master data จริง

- **ชื่อศาลซ้ำ 3 รายการ** ได้แก่ ศาลอุทธรณ์ภาค 9, ศาลฎีกา และศาลปกครองฎีกา
  ทำให้จำนวนศาลไม่ซ้ำเหลือ 296 จาก 301 รายการ
- **ศาลรัฐธรรมนูญ** ถูกจัดอยู่ใต้กลุ่มชื่อ `ศาลปกครองสูงสุด` ในข้อมูลต้นทาง
  ซึ่งไม่สอดคล้องกับระบบศาล
- **ประเภทคดีไม่ได้ระบุครบทุกแถว** ศาลปกครองและศาลทหารไม่มีการระบุประเภทคดีไว้

รายการเหล่านี้ยังไม่ได้แก้ไขในเอกสาร เพื่อให้ตรงกับข้อมูลต้นทาง
