## รายละเอียดรายเมนู

### 1. แดชบอร์ด

ประกอบด้วย

- ภาพรวมสำนักงาน
- รายการคดีความทั้งหมด
- รายการบริการด้านกฎหมายทั้งหมด
- รายการลูกความทั้งหมด
- รายการทนายทั้งหมด
- ภาพรวมรายได้
- ภาพรวมงาน
- ภาพรวมการนัดหมาย
- ภาพรวมสถานะคดีและบริการด้านกฎหมาย

**ทำอะไรได้:** ดู


### 2. ดำเนินคดีความ

#### รายการคดีความ

**ทำอะไรได้:** ดู/สร้าง/แก้ไข/ยกเลิก · Export · Conflict Check ลูกความและทนาย

#### เอกสารที่เกี่ยวข้องกับคดีความ

ประกอบด้วย

- ฟอร์มใบแต่งทนายความ (9)
- ฟอร์มใบแต่งทนายความ (อม.13)
- ฟอร์มใบแต่งทนายความชั้นอุทธรณ์ (อม.13/1)
- ฟอร์มใบมอบฉันทะ/ใบมอบอำนาจ
- ฟอร์มใบแต่งทนายความ ธน.113
- ฟอร์มใบมอบฉันทะ (9)

**ทำอะไรได้:** ดู/สร้าง/แก้ไข · Export · Auto generate and preview


### 3. บริการด้านกฎหมาย

#### รายการบริการด้านกฎหมาย

**ทำอะไรได้:** ดู/สร้าง/แก้ไข/ยกเลิก · Export · Conflict Check ทนาย

#### จัดการเอกสารทั่วไป

ประกอบด้วย

- หนังสือมอบเอกสารทั่วไป
- สัญญาจ้างที่ปรึกษา/ทนายความ
- ใบเสนอค่าบริการวิชาชีพ

**ทำอะไรได้:** ดู/สร้าง/แก้ไข · Export · Auto generate and preview


### 4. งานทั้งหมด

**ทำอะไรได้:** ดู/สร้าง/แก้ไข · จับเวลาการทำงาน
